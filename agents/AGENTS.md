## Herdr desktop app

If `$HC_TERMINAL_ID` is set and `$HERDR_ENV` is not `1`, you run in the Herdr desktop app.
In that case, read `~/Project/self/dotfiles/agents/skills/herdr-app/SKILL.md` before you create worktrees, start subagents, open tabs, run dev servers, or track PRs.
If `$HC_TERMINAL_ID` is not set, ignore this section.
